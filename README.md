# Система хранения исследовательских заметок

## Назначение

Хранить наблюдения, идеи и результаты исследований с привязкой к автору,
проекту и тематической категории.

## Целевая аудитория

Исследователи, студенты, аспиранты и небольшие научные группы.

## Предметная область и сущности

Исследователь ведёт проекты и создаёт заметки. Каждая заметка относится
к одному проекту и одной категории. Категория объединяет заметки по теме.

## Основные функции ПР1

- Проверка названия заметки.
- Оценка времени чтения по количеству слов.
- Вывод состояния заметки: активна или в архиве.

Запуск: `python main.py` (Python 3.10 или новее).

## План развития

ПР2: коллекции, функции, модули, JSON, меню, pytest и flake8.
ПР3: классы исследователя, проекта, категории и заметки.
Далее: Django, база данных, пользователи, REST API, Docker, CI/CD.
