# Система хранения исследовательских заметок

Учебное консольное приложение на Python для хранения идей, наблюдений и результатов исследований. Каждая заметка связана с автором, проектом и категорией.

Возможности:

- Создание, просмотр, редактирование и удаление заметок.
- Поиск и фильтрация по автору, проекту и категории.
- Архивирование и восстановление заметок и проектов.
- Управление исследователями, проектами и категориями.
- Автоматическое сохранение данных.
